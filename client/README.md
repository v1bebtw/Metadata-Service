# Metadata Service — клиент (Lab 4)

React + Vite: список документов, `useState` / `useEffect`, фильтр по типу файла, статистика, `localStorage`.

```bash
cd client
npm install
npm run dev
```

Откроется `http://localhost:5173`. После перезагрузки страницы список восстанавливается из `localStorage` (ключ `metadata-documents`).
